# Archive reading branch

Local branch `feat/0.7-archive-reading`, based on compression prototype `f6de759`
from `feat/log-autocompression`. The compression branch is its explicit prerequisite.

## Scope

Verified byte ranges, a bounded-memory file-like reader, and stable archive access.

```console
ocura-oss logs atom-<id> --stream stderr --offset 1024 --length 256
ocura-oss logs atom-<id> --archive
ocura-oss verify --archive --json
```

Offsets address original decoded bytes in raw or gzip backing. The complete
selected stream is checked before output, including content outside the requested
range. Only the returned window is retained: up to 1 MiB in memory, with larger
windows using OS temporary storage. A short excerpt avoids a complete decoded
disk copy; checksum verification still requires a complete source scan.

```python
from ocura_oss import Store

store = Store("experiment", archive=True)
with store.open_verified_log("atom-<id>", offset=0, length=256) as source:
    excerpt = source.read()
```

The returned snapshot is seekable, closes on context exit, and remains stable
after backing storage changes. The existing bytes-returning reader is unchanged.

## Stable archives

Archive mode avoids creating locks inside the ledger and rejects mutation methods.
Stop writers and finalize or recover unfinished attempts before using it. Content
reads and verification reject unfinished attempt records. The mode assumes stable
storage and does not coordinate with writers; normal mode retains its locks.
Large windows need writable OS scratch space outside the archive.

The archive remains an ordinary ledger directory, with no new container or record
schema. Runtime dependencies remain empty and the 64 KiB wheel budget is unchanged.
See the [CLI](../cli.md#stable-archives) and
[Python API](../python-api.md#storeopen_verified_log).

## Branch boundary

This branch contains no run-discovery interface or metadata scan optimization.
`tests/test_archive_reading.py` contains the eleven reader/archive tests split
from the combined prototype; the inherited compression and reader suites also
remain applicable. The earlier combined benchmark is a reference, not a new
measurement of this isolated branch.
