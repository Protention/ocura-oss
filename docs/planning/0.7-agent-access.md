# Agent access branch

Local branch `feat/0.7-agent-access`, based directly on released `v0.6.0`
(`fa4e5df`). This is an unreleased, independently reviewable change.

## Scope

Paginated run discovery and focused inspection, through the CLI and `Store`.
The caller interprets results and assembles reports.

```console
ocura-oss runs --json --limit 20
ocura-oss runs --json --pathway pathway-<id> --outcome failed
ocura-oss runs --json --after atom-<id> --limit 20
ocura-oss show atom-<id> --json
```

`runs` includes earlier failed retries, orders by start time and ID, and returns
`next_after` when more matches exist. Every scanned atom's envelope and fields
must validate. It retains at most `limit + 1` candidates, without reading logs or
maintaining an index. Limits range from 1 to 1000, defaulting to 100.

Pages are a live view. An execution finalized later with an earlier start time
can appear behind a cursor; stop writers for a complete paginated snapshot.

`show` validates one run and its lineage and returns the atom, its pathway reason
and relationships, and recorded log identities. Command arguments require explicit
`--command`. Both commands label verification scope and leave log contents unchecked.

Python callers use `Store.list_runs()` and `Store.inspect_run()`. `RunPage` and
`RunInspection` live in `ocura_oss.store`; top-level exports are unchanged.
See the [CLI contract](../cli.md#runs-and-show) and
[Python API](../python-api.md#storelist_runs-and-storeinspect_run).

## Branch boundary

This branch needs no compression or archive-reading changes. The existing
bytes-returning reader and scan behavior of other commands retain their 0.6.0
contracts. Runtime dependencies remain empty and the wheel retains the existing
64 KiB budget.

`tests/test_agent_access.py` contains the seven focused access tests split from
the combined prototype. Full branch checks and packaging are verified separately
from that earlier combined result.
