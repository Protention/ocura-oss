# Metadata scan branch

Local branch `perf/0.7-metadata-scans`, based directly on released `v0.6.0`
(`fa4e5df`). This is an unreleased, independently reviewable optimization.

## Scope

Pathway listing collects the pathways with recorded atoms in one atom scan.
Comparison selects each child's newest atom during one shared scan. Previously,
these commands scanned atom metadata separately for each pathway or child.

The command shapes, returned fields, newest-run selection, outcomes, and evidence
verification stay the same. This branch introduces no new runtime dependencies,
modules, storage format, or public interface. The existing 64 KiB wheel budget applies.

`tests/test_metadata_scans.py` checks that a history with several child pathways
requires one atom listing for each operation. The existing branching and CLI
suites exercise selection and verification behavior.

## Branch boundary

This branch needs neither compression, archive reading, nor the new run-discovery
interface. The earlier combined prototype's timings motivated the extraction;
they are not fresh measurements of this branch. Its scope is the repeated-scan
removal, with independent tests and packaging checks.
